# 🎮 Pokédex

Uma Pokédex interativa desenvolvida com **React + Vite**, inspirada no universo Pokémon. 🐾

O projeto tem como objetivo reunir informações sobre diferentes Pokémon em uma interface dinâmica e intuitiva, explorando conceitos de desenvolvimento frontend, componentização e interatividade com React.

---

## ✨ Sobre o projeto

A ideia é criar uma experiência inspirada nas Pokédex dos jogos Pokémon, permitindo explorar criaturas, consultar seus atributos e encontrar Pokémon de maneira prática.

A aplicação é desenvolvida como uma atividade acadêmica, com foco na aplicação dos conceitos estudados e na criação de uma interface visual própria.

## ⚡ Funcionalidades

- 🔎 **Pesquisa:** encontrar Pokémon pelo nome ou ID.
- 🧬 **Filtros por tipo:** explorar Pokémon de diferentes categorias.
- 📊 **Atributos:** consultar estatísticas como HP, ataque, defesa e velocidade.
- 📖 **Detalhes:** visualizar informações individuais de cada Pokémon.
- 🧑‍🚀 **Treinadores:** consultar treinadores, suas insígnias e os Pokémon relacionados.

## 🚀 Como executar

### Instalação

**1. Clone o repositório**

```bash
git clone https://github.com/Nicolas-De-Almeida/pokedex-DIAW.git
```

**2. Acesse a pasta do projeto**

```bash
cd pokedex-DIAW
```

**3. Instale as dependências**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento**

```bash
npm run dev
```

🌐 Acesse o endereço exibido no terminal, geralmente `http://localhost:5173/`.
